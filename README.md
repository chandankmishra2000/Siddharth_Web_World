# Siddharth Web World — Website

Open `index.html` in a browser (or upload the folder to any web host).

```
site/
├── index.html · about.html · services.html · contact.html
├── css/style.css          all styling (design tokens at top)
├── js/boot.js             flags JS + decides if splash shows
├── js/splash.js           splash screen (once per browser session)
├── js/main.js             nav, reveal, counters, form → WhatsApp
└── assets/img/            logo-mark.png, favicon.png, siddharth-gahlot.jpg
```
Edit contact details / copy directly in the HTML files. WhatsApp number is set in `js/main.js` (WA_NUMBER).
